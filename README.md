## 📈 1분 투자 챌린지

가상 자금 **1,000,000원**으로 하는 주식 모의투자 게임입니다. 뉴스 속보를 읽고 오를 것 같은 종목을 골라 수익률을 높여 보세요.

### 하는 방법
1. 닉네임을 입력하고 모드를 고릅니다.
2. 라운드마다 뉴스 속보가 나오면 **10초 안에** 종목 1개 또는 현금 보유를 고릅니다.
3. 7개 종목이 얼마나 오르고 내렸는지, 왜 그런지 설명을 확인합니다.
4. **5라운드**가 끝나면 최종 수익률, 투자 성향 칭호, 자산 변화 그래프가 나옵니다.

### 모드
| 모드 | 뉴스 | 순위 · 선물 |
|---|---|---|
| 연습 모드 | 정답이 분명한 뉴스 8개 중 5개 | 없음 |
| 하드 모드 | 10개 분야 뉴스 31개 중 분야가 겹치지 않게 5개 | 오늘의 TOP 5, 수익률 **40% 이상이면 선물** |

### 특징
- 같은 뉴스에서 같은 종목을 고르면 결과는 항상 같아요(무작위 없음 → 공정한 순위).
- 빨강 = 상승, 파랑 = 하락
- 효과음이 나요. 화면 오른쪽 아래 버튼이나 **M 키**로 끄고 켤 수 있어요.
- 시작 화면에서 60초 동안 아무도 조작하지 않으면 **대기 화면**(TOP 5, 하는 방법)이 나타나요. 아무 키나 터치로 닫혀요.

### 키보드
| 키 | 기능 |
|---|---|
| `1` ~ `7` | 종목 고르기 |
| `0` | 현금 보유 |
| `Enter` | 닉네임 입력 후 하드 모드 시작 / 결과 공개 후 다음으로 |
| `M` | 효과음 켜기 · 끄기 |

## 🔮 오늘의 타로

연애운 · 학업운 · 금전운 중 하나를 고르고, 카드 3장을 뽑아 운세를 보는 게임입니다.

### 하는 방법
1. 보고 싶은 운세를 고릅니다.
2. 부채꼴로 펼쳐진 **카드 78장** 중 마음이 가는 카드 3장을 고릅니다.
3. 카드를 한 장씩 눌러 뒤집으면 그 자리의 해석이 나옵니다.
4. 세 장을 모두 뒤집으면 **별점(0~5개)**, 종합 운세, 행운의 색 · 숫자 · 아이템이 나옵니다.

### 특징
- 메이저 아르카나 22장 + 마이너 아르카나 56장(완드 · 컵 · 소드 · 펜타클), 타로 한 벌 전체
- 카드가 거꾸로(역방향) 나올 확률 35%, 역방향이면 뜻이 달라져요.
- 별점 확률: 0개 0.6% · 1개 8.6% · 2개 26.7% · 3개 51.2% · 4개 9.8% · 5개 3.1%

> 타로는 재미로 보는 운세예요. 좋은 말은 믿고, 나쁜 말은 조심하라는 뜻으로 받아들여 주세요 🙂

## 🛠️ 부스 운영 팁

- 브라우저에서 **F11**을 누르면 전체 화면으로 운영할 수 있어요.
- 인터넷 없이도 동작해요. HTML 파일을 내려받아 더블클릭해도 됩니다.
- **투자 게임의 순위표와 기록은 각 기기의 브라우저에 저장돼요.** 휴대폰 등 다른 기기에서 한 기록은 부스 컴퓨터의 TOP 5에 나오지 않으니, 부스는 컴퓨터 한 대에서 운영하는 걸 권장해요.
- 순위는 날짜별로 따로 쌓여요. 하루가 지나면 새 순위표가 시작돼요.
- 투자 게임 시작 화면 아래의 **기록 CSV 내보내기**로 오늘 기록을 엑셀로 옮길 수 있어요. **오늘 기록 초기화**는 실수 방지를 위해 두 번 눌러야 실행돼요.

### 게임 고친 뒤 다시 올리는 방법
게임 원본(파이썬)은 이 저장소가 아니라 부스 컴퓨터의 `booth.ipynb` 폴더에 있어요.

```bash
cd booth.ipynb
python maingame.py --no-open        # invest_challenge.html 만들기
python tarot.py --no-open           # tarot.html 만들기
python build_booth_all.py           # booth_all.html 만들기

cp invest_challenge.html ../pages/invest.html
cp tarot.html ../pages/tarot.html
cp booth_all.html ../pages/booth.html

cd ../pages
git add . && git commit -m "게임 업데이트" && git push
```

push 하고 1~2분 뒤에 링크에 반영돼요.

> `git push`에서 `could not read Username` 오류가 나면 `gh auth setup-git`을 한 번 실행한 뒤 다시 push 하세요.
